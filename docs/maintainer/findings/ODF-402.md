## ODF-402 — Stopping an already-ended CI mailbox crashes without a result

**Meaning:** `ci-mailbox.mjs stop` on a recorded mailbox directory that has disappeared throws an unhandled ENOENT stack and reports no terminal result, so shutdown has to be verified by hand.

**Follow-up:** Open, unqueued; not resolved.

**Identity / assessment (2026-11-03):** New concrete issue. One execution on 0.3.79; shutdown itself succeeded. Whether the first call removed the mailbox before failing is unknown. Maintained guidance assessed at `325f9de8a1f635a44b0071cf0660a2593a21f6b9`.

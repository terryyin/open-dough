## ODF-264 — Broad startup reads lose required context to truncation

**Meaning:** An agent batches whole workflow references or unbounded metadata beyond the response budget, loses requested passages to truncation and repeats retrieval before delegation.

- **Follow-up:** Open, unqueued.
- **References / identity:** Distinct from ODF-158: the source identifies an execution deviation under already-applicable targeted-retrieval guidance, whereas ODF-158 concerns the cost of required broad reads. Seven distinct supplied executions; repeated tool calls within an execution do not increase that count. Some execution releases and all unrecorded event times remain unknown; no general saving is measured. Current guidance assessed: `327b6fa255b84ba8a2552ca41dba37a46fadf4d9` (0.3.65); this is the review revision, not substituted execution provenance.

### Response and evaluation (2026-10-20)

Plan 323 replayed the stylesheet-extraction case natively before any remedy
(`tests/proof-scheduling-native.sh`, case `delivery-evidence/scheduling`). The
harness logs every product proof run with its kind and product-state identity,
reruns the suite on the final state, and rejects redundant pre-move runs,
stale, partial or invocation-only final coverage, a broken consumer, and an
implementation-time extraction as an unreached boundary. Harness commits:
`788d817296adfc0b23a672489619b3ea8bbaf52a` and
`5484e053f5ac4ee21ea84391656a24953d3f3644`. Guidance under test: the installed
copies at candidate `c6b37d26aa6ffe1c747c0b61c8065bf59d688ab9` (installed 0.3.66 payload).

- **Quick replay** (Claude Code 2.1.304; suite cost stated as about fourteen
  minutes; a stylesheet layout rule present): one suite run, on the final state.
  The coordinator implemented locally, put the new rules in a new stylesheet,
  and told the refactor agent not to run the suite.
- **Planned replay** (the maintainer's chosen historical conditions: a
  selected plan slice, no stated suite cost, no layout rule): one pre-change
  baseline suite run on the untouched state, then one suite run on the final
  state. The coordinator again implemented the single selected slice locally
  and extracted during implementation; the refactor made a comment-only edit
  and ran no suite.

Neither replay reproduced a broad run between implementation and a
refactor-time move. Limits: one attempt each on one host; the
delegated-implementer condition of both occurrences was not reached, since
current guidance lets a coordinator implement one selected slice itself; plan
302's misjudged suite cost and plan 310's explicit whole-suite briefs were not
replayed as instructions. The planned replay showed a different, smaller cost:
an unrequested pre-change baseline suite run. The maintainer decided before the
second replay to close without a guidance change if it did not reproduce. First
containing release: none (no product guidance changed); adoption not applicable.
Recurrence with a delegated implementer would reopen the remedy with the
retained harness.

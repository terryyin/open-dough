## ODF-419 — A delegated smoke check mutates the owner desktop

**Meaning and assessment:** A probe child helper called the real clipboard clear operation on the coordinator host during a smoke check. One actual mutation is supported; no unique data loss is known. ODF-307 concerns foreground interference, while this operation changes live desktop data. Unknown execution release limits shared attribution and any post-response claim.

**Follow-up:** Open, unqueued.

An implementation agent import-checked a new Linux probe support module on the
macOS coordinator host by calling its `child_clear()` helper, which ran the

delegation brief had not said that probe child helpers act on the live
clipboard of whatever host runs them.

# Voice slice experiment

The mounted voice scenarios test recording and dismissal while a LaunchDialog is open. The hypothesis is that starting the existing fixture open and using its ordinary viewport removes the first pointer action and viewport resize from every case while leaving native reopening, Record, Stop, Cancel and Escape intact.

Run the maintained three-file selection at two workers on awake AC macOS. Compare an unchanged pass, one disposable phase trace, and one simplified fixture pass. Repeat the pair only if host load or startup variation masks a meaningful saving. Keep the smaller setup and report any timing uncertainty. The active recording test will separately show each dismissal ends a real track if the existing cases leave the Cancel path uncovered.

Budget up to 90 seconds of elapsed time for each focused run under variable natural load. No other owned proof is running. The fixture's browser inputs and real audio stay in the same runner mode with no timeout or autoplay setting changes. Capture natural load and the exact cases.

## ODF-430 — Story integration moves another active agent profile into `done/`

**Meaning:** An incoming trunk merge infers a directory rename from `.planning/agents/` to `.planning/done/` and relocates an active story's unchanged agent profile into `done/`, requiring manual restoration and done-catalog rebuild before closure.

**Follow-up:** [Preserve live agent profiles when integrating stories](https://github.com/terryyin/open-dough/blob/29cc4f0d289e0584c38f766d4a08d503d1fc4d9c/.planning/seeds/SEED-010-learn-from-execution-retrospectives.md#preserve-live-profiles-during-integration) — SEED-010#preserve-live-profiles-during-integration. Response delivered 2026-11-08 (see Delivered response below), unreleased after 0.3.91; not yet resolved by ordinary use, and the finding remains open.

**References / identity:** open-dough / DD-436 → ODF-430. Unseen concrete issue in `dough-product-backlog` merge/integration handling. One Open Dough execution (`0.3.86`). Current maintained guidance assessed: `626ecc24b28c398eaa4543e19936a415c526c0e9` (`0.3.87`).

### Delivered response (2026-11-08)

Delivered by SEED-010#preserve-live-profiles-during-integration (plan 522, recoverable at `29cc4f0d289e0584c38f766d4a08d503d1fc4d9c`) in
story branch commits; the retained evidence and occurrence above are unchanged.

- **Prevention (slice 1, `fc60c5e1c9fae79774b7828761cb48994af369ec`):** the
  product-backlog adapter's merge runs with directory-rename inference off, so
  a live agent profile stays in `.planning/agents/` when the other side
  completes the story holding the last profile there.
- **Hold (slice 2, `c15cf0606c337b8fe2fd8a888de50c2279d1b56e`):** the adapter's
  `continue` and every publisher hold a result that places an agent profile
  under `.planning/done/`, naming each such path and its `.planning/agents/`
  home.
- **Scope:** slice 1 prevents the inferred directory move recorded here; slice 2
  holds any remaining path that would publish a profile among the done records.
  This response repairs no existing trunk history; the affected trunk records
  were already restored by the executions in the occurrence above.
- **Containing release:** unreleased after 0.3.91 until a release contains
  both commits.
- **Ordinary-use criterion:** the next observed concurrent integration in
  which one side completes a story while another is active keeps that profile
  in `.planning/agents/` and adds no profile to `.planning/done/`. Until then
  the finding is delivered, not resolved.

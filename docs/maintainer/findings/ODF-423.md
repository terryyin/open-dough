## ODF-423 — Permission-refused remote push returns `needs-validation` without the remote's refusal text

**Meaning:** Managed delivery treats a remote permission/policy refusal (such as missing OAuth `workflow` scope) as an ordinary rejected push, reconciles onto the unchanged remote tip, and stops with `needs-validation` without surfacing the remote's refusal text.

**Follow-up:** Open, unqueued; not resolved.

**References / identity:** open-dough / DD-418 → ODF-423. Unseen concrete issue in `execution-increment-publication.mjs`; one Open Dough execution (unknown release; checkout VERSION `0.3.83`). Current maintained guidance assessed: `626ecc24b28c398eaa4543e19936a415c526c0e9` (`0.3.87`).

## ODF-229 — Interrupted Cursor implementation loses its proof return

**Meaning:** An interrupted Cursor implementation Task leaves edits but no agent return; the coordinator must reconstruct proof and acceptance from the checkout.

- **Follow-up:** Deterministic response delivered 2026-10-20, released in 0.3.67, not resolved: [Stop and acknowledge Cursor sessions safely](https://github.com/terryyin/open-dough/blob/718a0291d5444d9cdef33e3acc518ba8e44e14a1/.planning/seeds/SEED-052-start-agent-work-from-dashboard.md#safe-cursor-session-stop) (spent section, recoverable at the before-cleanup revision), selected by Terry on 2026-10-20, delivered its deterministic response in plan 327 (see Delivered response, 2026-10-20 below); resolution awaits native observation, which remains pending and named, not passed.
- **References / identity:** separate uncertain relationship; ODF-059 already includes implementation agents as well as refactors, so role alone is not a difference, but this report does not establish its watchdog termination cause; ODF-204 continued unauthorized publication is absent
- **Release assessment (2026-10-21):** Inspected interruption-recovery change `e1bdd5ac` (plan-327 slice-4 change `07f0c521`) and current `delegation.md#recover-an-interrupted-delegated-result`; both revisions first occur in `v0.3.67` (`578e289a`). The protocol requires actual checkout/remote inspection and renewed focused proof before replacement writers or acceptance, and a developer decision on unexpected commits. It claims no control over an already-running delegated Task. ### Delivered response (2026-10-20)

Delivered by SEED-052#safe-cursor-session-stop (plan 327) on this branch; the retained evidence and occurrence above are unchanged.

- **Coordinator guidance (slice 4, `07f0c521`):** `src/skills/dough-execute-plan/references/delegation.md` now requires a coordinator whose delegated implementation or refactor call is interrupted with no return to treat the slice as incomplete and to re-establish focused proof from the checkout — inspecting its diff and plan and the remote branch for the interrupted agent's commits — before any acceptance, replacement writer, formatter, or delivery. This matches the recovery the coordinator in the occurrence above actually performed (inspected the uncommitted diff, re-ran focused proof from the checkout), and never accepts work on a promised or later-claimed return.
- **Related dashboard delivery, with its limit:** plan 327 slices 2–3 also delivered a runner-confirmed Cursor Stop (with a durable unconfirmed explanation and a replacement-writer block/override) and a local-only Done acknowledgement. That dashboard Stop acts on the runner-held Cursor session; it is not claimed to control an in-session delegated Task.
- **Deterministic proof that exists:** the execute-plan guidance tests (`src/skills/dough-execute-plan/scripts/interrupted-delegation-guidance.test.mjs`) pin the interrupted-delegation recovery contract, and the fake-Cursor dashboard journeys (`dashboard/tests/agent-session-cursor-stop.spec.ts`, `dashboard/tests/agent-session-cursor-done.spec.ts`) pin the confirmed/unconfirmed Stop behavior and the local-only Done acknowledgement.
- **Remaining gap — native proof pending, not passed:** no native Cursor verification run was performed in this execution, and no native interrupted-Task reproduction was run. Whether SIGHUP/hangup actually terminates a native in-flight Cursor turn or its delegated subagents, and whether this guidance changes native outcomes, remain unproven (ADR 0005). Resolution of this finding awaits that native observation; it is not declared resolved or closed here.

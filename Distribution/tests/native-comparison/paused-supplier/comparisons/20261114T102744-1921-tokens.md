## Conditional typical-task estimate

- An ordinary task that never blocks avoids zero wakes: approximately 0 tokens
  saved, with possible small extra guidance overhead.
- At the observed baseline context, eliminating one unchanged wake would avoid
  about 218k gross tokens across 3 model requests. About 206k of those were cached
  input; uncached input plus output was 12,139. This is a unit-cost projection,
  not observed daemon savings or a billing estimate.
- Two such avoided wakes project about 437k gross tokens; five about 1.09M; ten
  about 2.18M. Setup, continuation and worker cost changes must be subtracted
  before claiming net task savings.
- Candidate initial hold used 464,479 more tokens in this CLI observation, and
  qualification used about 4.0M more. Neither cost is established as the
  daemon path's fixed overhead; subtracting only initial cost would give an
  unsupported net forecast.

A population estimate needs the frequency/length of supported blocks and a
matched event-driven run that actually suppresses wakes. Those are unmeasured.
The current defensible net estimate for typical tasks is therefore unknown,
with 0 demonstrated savings; the gross per-avoided-wake projection is conditional.
Known earlier SEED-345 coordinator observations cost at least 7,548,006 tokens;
this pair adds 21,821,237 observed native tokens. Overall implementation/worker
cost is larger or unknown. No implementation break-even is claimed without a
positive net saving.

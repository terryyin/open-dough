# Dashboard Backend Test

Use Node Vitest to exercise typed dashboard server handlers and request
admission in process. Put specs and case definitions in the feature folder
for the behavior they cover. Share harness fixtures through
[Dashboard Test Support](../test-support/).

Use the [end-to-end suite](../../e2e/README.md) for behavior that requires a
running dashboard or a browser workflow. Component behavior belongs in the
[frontend test suite](../frontend-tests/).

## ODF-482 — A pre-Take merge base causes a false source-freshness hold

**Meaning:** Several best merge bases can coexist after history-preserving sibling imports. Choosing the pre-Take base can misidentify the comparison for a valid Take.

**Follow-up:** Open, unqueued.

**References and limits:** A distinct graph-selection issue from [ODF-403](ODF-403.md). Source coverage and later integration remain evidenced in the original execution.

### Retained evidence — Open Dough / DD-481 (2026-11-13)

**Source mapping:** [Open Dough / DD-481](https://github.com/terryyin/open-dough/blob/07407e12b40115862205041f03e27851b361cfb2/DearDough.md#L525).

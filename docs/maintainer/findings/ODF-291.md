## ODF-291 — A later slice's planned fixture contradicted an earlier slice's planned entry point

**Meaning:** A later planned fixture re-enters a resource lifetime made exclusive by an earlier planned service entry, so the plan contradicts its own seam proofs.

- **Follow-up:** Open, unqueued.
- **References / identity:** Pygardon / DD-265 → ODF-291. One 0.3.63 execution. The failed fixture attempt produced a visible stop and an owner decision; it did not silently relax lifetime ownership. This is a cross-slice plan incompatibility, distinct from ODF-233’s plan forbidding the representation its behavior needs.

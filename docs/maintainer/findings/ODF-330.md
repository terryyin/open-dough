## ODF-330 — Hand-built delivery paths corrupt porcelain status spacing

**Meaning:** A hand-built owned-path list trims significant porcelain status spacing and corrupts a path; the input guard contains the mistake before project commands.

**Follow-up:** Open, unqueued; not resolved.

**Identity and limits:** New concrete issue at the supplied execution provenance. Related symptoms elsewhere do not establish a common cause. The guard contained a caller-input error; no delivery-tool defect is established. Current maintained guidance assessed: `f274a3d0c729504bf8ce00614bf3cd236b7e088b` (source through 0.3.71); this is not substituted execution provenance.

## ODF-411 — A delegated agent marks the slice done before delivery

**Meaning:** An implementation or refactor agent writes `Status: done` on the active slice before delivery, which owns that transition; the coordinator reverts it or delivery proceeds over a premature done.

**Follow-up:** Open, unqueued; not resolved.

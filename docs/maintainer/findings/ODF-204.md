### Delivered response (2026-10-20)

Delivered by SEED-052#safe-cursor-session-stop (plan 327) on this branch; the retained evidence and occurrence above are unchanged.

- **Coordinator guidance (slice 4, `07f0c521`):** `src/skills/dough-execute-plan/references/delegation.md` now requires a coordinator whose delegated call is interrupted with no return — or whose interrupted agent later claims work — to treat the slice as incomplete, inspect the checkout's diff and plan and the remote branch for the interrupted agent's commits before any replacement writer, formatter, or delivery proceeds, re-establish focused proof from the checkout before acceptance, and pause for the developer's decision on any unexpected commit. Delivery never proceeds on the interrupted agent's claim.
- **Dashboard Stop limit, stated plainly:** plan 327 slices 2–3 also delivered a runner-confirmed Cursor Stop (with a durable unconfirmed explanation and a replacement-writer block/override) and a local-only Done acknowledgement. That dashboard Stop acts on the runner-held Cursor session; it is **not** claimed to control an in-session delegated Task, and nothing delivered claims it would have stopped the agent in the occurrence above.
- **Deterministic proof that exists:** the execute-plan guidance tests (`src/skills/dough-execute-plan/scripts/interrupted-delegation-guidance.test.mjs`) pin the recovery contract, and the fake-Cursor dashboard journeys (`dashboard/tests/agent-session-cursor-stop.spec.ts`) pin the confirmed stop, the durable unconfirmed explanation, and the replacement-writer block/override.
- **Remaining gap — native proof pending, not passed:** no native Cursor verification run was performed in this execution. Whether SIGHUP/hangup actually terminates a native in-flight Cursor turn or its delegated subagents, and whether this guidance changes native outcomes, remain unproven (ADR 0005). Resolution of this finding awaits that native observation; it is not declared resolved or closed here.

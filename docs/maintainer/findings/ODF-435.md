## ODF-435 — Test-removal plan maps story examples to surviving tests without checking a deleted test's other observations

**Meaning:** A test-removal plan maps each story key example to a surviving test without checking what else a deleted test observed, briefly dropping the only test of another learner-visible behavior until the implementer's gap report restores a dedicated case.

**Follow-up:** Open, unqueued; not resolved.

**References / identity:** doughnut / DD-344 → ODF-435. Uncertain relationship to ODF-210 (product removal omitting a user capability). One Doughnut execution (`0.3.82`). Current maintained guidance assessed: `626ecc24b28c398eaa4543e19936a415c526c0e9` (`0.3.87`).

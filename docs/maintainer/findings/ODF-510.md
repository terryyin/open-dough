## ODF-510 — The source-review recorder leaves an incomplete reverse link for a shared obligation

**Meaning:** Creating an obligation from one commitment writes a partial reverse link. Recording other commitments for the same obligation does not update it, so normal validation refuses the result.

**Follow-up:** Open, unqueued. The saved plan was repaired. Distinct from ODF-391’s hand-edited observation grammar and linked to the many-to-one evidence case in ODF-481. [ODF-514](ODF-514.md) covers a distinct update path that discards an existing complete reverse link.

**Identity and limits:** Open Dough / DD-534 → ODF-510. Source assessed at `face6fd05b3f5c4f20159db9b41480afbe90d592`. Execution provenance below governs the observation.

**Source:** [Open Dough / DD-534](https://github.com/terryyin/open-dough/blob/face6fd05b3f5c4f20159db9b41480afbe90d592/DearDough.md#L990).

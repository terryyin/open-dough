# Comparable packet rules and reusable templates

A and B consume the same frozen common bundle. Record its digest in each packet.
Preserve the complete raw population, each path's disposition, group membership,
source/evidence locators, I0/H0 and proof outcomes. No path/category rule establishes
semantic exclusion. New producer evidence enters the common bundle before review.
Do not silently replace the population or provide one arm private facts.

## A: current complete handoff template

- Case identity, immutable source/base/candidate, guidance and common bundle digest.
- Observable promise, I0/H0, selected proof, actual outcomes and unresolved claims.
- Full raw path/term population in original order, with each path's disposition,
  evidence and purpose link; linked proof retains its actual scope.
- Acceptance claim and evidence limitations.

## B: compact handoff template

- Same identity, promise, I0/H0 and evidence digest.
- Effect → responsibility → observing assertion → actual proof or explicit gap.
- Navigation groups based on inspected evidence, with reason/evidence and complete
  membership. Each raw path retains a disposition and group/evidence link.
- Same full raw population, proof facts, acceptance claim and limitations as A.

Use REVIEWER-BRIEF.md unchanged for either arm, substituting only the packet
locator. Reviewers cannot see the other arm, assessor reference or earlier report.
Use two fresh same-configuration tasks sequentially. Record order before dispatch.
No duplicate test runs or edits. Timing is observed dispatch to returned result.
Calibration records below rehearse known examples and are never prospective cases.

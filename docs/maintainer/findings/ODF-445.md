## ODF-445 — Multi-OS GitHub Actions CI-proof recipe omits `shell: bash` for Windows runners

**Meaning:** `dough-test-optimization/references/ci-proof-summary.md` step 3 gives a POSIX shell snippet (`${GITHUB_RUN_ATTEMPT}`, `${CI_PROOF_REVISION}`, `${RUNNER_TEMP}`) without noting `shell: bash` when the producer job is a multi-OS matrix including Windows, where GitHub Actions defaults to PowerShell.

POSIX shell conditionals (`if`, `$?`, `RUNNER_TEMP`) were added to a
`ubuntu`/`macos`/`windows` desktop-free matrix without `shell: bash`. Windows
runners default to PowerShell, so the first hosted run rejected those steps
while the Ubuntu Intent proof fragment and summary already matched the named
leg — one CI repair round-trip to set `shell: bash` on the affected steps.

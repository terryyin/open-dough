## ODF-495 — The whole-suite gate names a command that excludes its target suite

**Meaning:** A plan assumes an umbrella test command covers the dashboard browser journeys that justify the gate. The executed command runs a different set and consumes a local proof window.

**Follow-up:** Open, unqueued.

**References and limits:** The affected command definitions are repository-specific. [ODF-074](ODF-074.md) owns the established premise-checking response. The retained result demonstrates a concrete suite-selection mistake and carries no new runner change.

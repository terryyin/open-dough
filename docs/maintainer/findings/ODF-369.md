## ODF-369 — A delegated broad test run with no external time bound busy-spun for 32 hours while the coordinator waited

**Meaning:** An implementation agent launched a broad lifespan pytest selection without an external wall-clock bound and waited on it. A test seam faked the shared wall-clock sleep process-wide, the slice's new lifespan loop picked it up, and the fake never yielded, so one xdist worker spun the event loop and the in-process hang bound (`HANG_TIMEOUT_SECONDS`) could never fire. The coordinator waited on the agent's notifications without a liveness check.

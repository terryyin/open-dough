## ODF-059 — Interrupted agent handoffs
A host-terminated refactor agent leaves changes without a report, requiring recovery from the actual diff and unresolved proof.

- **Follow-up:** Recovery guidance released in 0.3.67; effectiveness unverified, not resolved. No additional implementation story selected. **Evidence:** [open-dough](https://github.com/terryyin/open-dough/blob/c76322764499936acd42328b5ef4f66f4df6bcf8/DearDough.md#odf-059--delegated-refactor-pass-stalled-after-editing-and-before-reporting).
- **Earlier response limit:** At the earlier assessment, delegation guidance had no lost-agent protocol. Doughnut plan 132 (0.3.24) reported the same; its log entry was pruned on 2026-10-03.
- **Current assessment (2026-10-21):** `e1bdd5ac` adds `delegation.md#recover-an-interrupted-delegated-result`: an interrupted implementation or refactor call without a return stays incomplete; inspect actual diff, plan and remote before replacement writers or delivery, re-establish focused proof, and leave unexpected commits to the developer. Its first containing tag is `v0.3.67` (`578e289a`). This replaces the no-protocol claim, not the historical observations. It neither stops an already-running agent nor establishes recovery from every host termination. Native follow-through and relevant later use remain unverified here; release or installation alone starts no watch. ODF-204 and ODF-229 retain their distinct or uncertain causes.

- **Additional evidence:** Open Dough plan 246 / `0ae01bd4`, 2026-10-05, Claude Code / 0.3.56: a 600-second watchdog stopped an implementation agent with 17 edited files and no report; owned stash/restore and resuming the same agent recovered them. This is the third Open Dough execution with this mechanism; no work was lost.

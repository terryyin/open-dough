# Choose Claude Code effort when starting a session

<a id="choose-claude-code-effort"></a>

### Choose Claude Code effort when starting a session

**Identity:** SEED-280#choose-claude-code-effort

**Goal.** A developer starting a Claude Code session from the dashboard can
choose its reasoning effort for the work at hand.

**Scope.** Offer a Claude Code effort choice in the session-start dialogs for
project sessions, follow-ups, and story workflows. Offer supported effort
levels and the option to use the Claude Code default.

**Key examples.**

- Select Claude Code and an explicit effort, then start a session. The
  session starts with the selected effort.
- Start a Claude Code session with the default selected. Claude Code uses
  its configured effort.

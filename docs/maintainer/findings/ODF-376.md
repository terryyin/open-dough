## ODF-376 — Codex stream can yield before exposing observer identity

**Meaning:** The prescribed Codex binding prints the observer directory only in its initial
tool result. If checkout setup or provider discovery outlasts that yield, a later
`CI_OBSERVER` line is parsed without exposing the identity to the coordinator.
Consider emitting identity when it becomes available, within the existing binding.

**Follow-up:** First released in 0.3.76; installed adoption verified in all five maintained projects. Ordinary use of the released binding verified in Pygardon; qualifying delayed-identity ordinary use and watch start remain pending. Not resolved.

**Identity / limits:** Pre-fix maintained guidance assessed at `70b99adc80609fa23867165620c2543f050c0cea`. Supplied execution releases, dates and unknowns below are preserved; collection time adds no occurrence or post-fix claim. Identity receipt can be missing even when later batch acknowledgment exists; preserve setup/PTY uncertainty.

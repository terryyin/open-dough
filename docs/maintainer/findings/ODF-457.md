## ODF-457 — A scripted test move drops a moved test

**Meaning:** A refactor pass that mechanically moves tests between spec files can cut a test without writing it to its destination; nothing compares test titles before and after the move.

**Follow-up:** Open, unqueued.

**Identity and limits:** Open Dough / DD-457 → ODF-457. Unseen concrete issue. One execution; the refactor agent recovered the test from its own saved diff. Maintained source assessed at `220026a4e1b8409ffa81f50cd8e3130945ff8472` (0.3.93).

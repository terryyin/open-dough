## ODF-325 — Empty delegation while waiting

**Meaning:** A coordinator starts a no-op agent solely to stay active while real delegated work is pending, despite an existing waiting rule.

**Follow-up:** Open, unqueued; not resolved.

**Identity and limits:** New concrete issue at the supplied execution provenance. Related symptoms elsewhere do not establish a common cause. Existing guidance already forbids empty waiting calls; one observed violation warrants no wording response.

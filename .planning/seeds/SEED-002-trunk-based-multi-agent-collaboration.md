# SEED-002: Try shared-branch collaboration on real work

## Idea

When interdependent agent work exposes a coordination problem, try one bounded
shared-branch task. Use existing communication and Git tools. The affected agents
coordinate a compatible change while the maintainer reviews the integrated result.
Restore working shared code promptly when integration causes a failure.

## Value and evaluation

Learn whether direct coordination helps finish that actual task. Judge the
experiment by useful integrated behavior and the effort needed to resolve overlap.
Manual coordination is the starting approach.

## When to surface

A real shared-branch conflict makes this experiment useful. Choose the task and
estimate it then. Keep this as an idea until that need arises.

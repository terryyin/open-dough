## ODF-491 — A test configuration change was offered with incomplete scope

**Meaning:** A coordinator described only the keyboard effect of a browser-wide scroll flag. Exercising the proposed option exposed the programmatic reveal behavior affected by the same flag.

**Follow-up:** Open, unqueued.

**References and limits:** The developer amended the decision before publication. The report does not establish a browser product defect.

### Retained evidence — Open Dough / DD-511 (2026-11-13)

**Source mapping:** [Open Dough / DD-511](https://github.com/terryyin/open-dough/blob/07407e12b40115862205041f03e27851b361cfb2/DearDough.md#L960).

The coordinator offered `--disable-smooth-scrolling` to the developer as "Key scrolls become instant … changes every dashboard test's key scrolling" and the developer chose it. Before the load proof, the implementing agent probed the flag and found it also makes programmatic smooth reveals instant, which removed the only browser proof of a reveal still in motion. A second decision was needed, and later a third: whether to delete the one spec that tested a reveal in motion.

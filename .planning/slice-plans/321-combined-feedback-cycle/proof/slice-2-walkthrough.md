## One final combined dashboard report

Representative input is an explicitly supplied absolute reporting command and
launch context, retained outside every child-retirable workspace. Trace:

1. Wrapper **Establish the cycle and project set** retains that context in the
   surviving run context and says the combined owner performs one final report;
   child maintenance/landing returns defer it.
2. **Complete the local phase** passes deferred combined reporting with the
   originating authority and selected target. Local delivery's final paragraph
   defers child landing's reporting until the complete triage response settles.
   The combined caller retains ownership beyond that return.
3. **Collect shared feedback** receives the same originating instruction,
   local gaps and accepted/unfinished facts. Its return cannot override the
   wrapper's combined reporting ownership. Later shared edits require separate
   acceptance; local acceptance alone cannot trigger completion.
4. **Report the settled result** first verifies actual saved records and remote
   ancestry for both phases. A partial alpha publication or beta missing input
   stays incomplete. An accepted publication with stopped default refresh is
   reported separately under completion attention.
5. The final link reaches maintained Dough Land **Completion attention** and
   `references/dashboard-completion.md`. It requires final wording after
   publication, required observation/shutdown, refresh and retirement; then the
   supplied command is the final operation. Quiet completed uses no message
   file; material attention uses the exact surviving message; unfinished uses
   `--outcome unfinished` and that exact message. A matching receipt is required.
   Lost acknowledgment uses the retained reporting-only retry and never repeats
   Git publication/retirement. Reporting does not declare story completion.

No reporting context was supplied to either fixture journey, so neither contacts
any dashboard. The wrapper/reporting consumer implementation is unchanged;
therefore the plan's conditional isolated reporting receiver is not triggered.
This review establishes the documented ownership/handoff/receipt path only; it
makes no fresh native receiver or production dashboard claim.

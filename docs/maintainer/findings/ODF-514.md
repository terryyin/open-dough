## ODF-514 — Updating a shared obligation discards existing reverse links

**Meaning:** Updating an existing obligation through the source-review writer without an explicit full commitment list replaces its existing reverse links with only the selected commitment. The command succeeds and a subsequent guard refuses the mismatch.

**Follow-up:** Open, unqueued. The originating plan’s links were repaired and the guard passed.

**Identity and limits:** Pygardon / DD-505 → ODF-514. The exact update default is present in installed 0.3.98 and maintained source `face6fd05b3f5c4f20159db9b41480afbe90d592` (0.3.101). [ODF-510](ODF-510.md) concerns creating a partial reverse link and subsequent observation-only updates leaving it incomplete. This case replaces links on an existing entry. Both affect the same many-to-one invariant and may share a bounded response.

**Source:** [Pygardon / DD-505](https://github.com/terryyin/pygardon/blob/4e9f1a43f8a9e91d0fc44644311f11a158d41236/DearDough.md#L809).

## ODF-360 — A new installed command assumed a writable system temp directory that host sandboxes refuse

**Meaning:** A command added for coordinators to run (`source-freshness.mjs`) made its scratch directory with `mkdtemp(os.tmpdir())`. Every credential-free proof ran unsandboxed, so the first paid Codex round found that its workspace-only sandbox refuses the system temp directory and `/tmp`; the round failed and a fix plus a retry followed.

**Follow-up:** Scratch-directory response `2b46202c` integrated and first released in `v0.3.73`; ordinary host outcome pending, not resolved.

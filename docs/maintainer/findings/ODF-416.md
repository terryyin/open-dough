## ODF-416 — A progress increment holds a locally accepted Behavior slice open

**Meaning:** Publishing a Behavior increment with `progress: true` keeps the slice planned until CI confirms, although local proof is the authorized done floor and CI is observation only; a second records-only commit marks it done and cancels CI on the superseded revision.

**Follow-up:** Open, unqueued; not resolved.

**Identity / assessment (2026-11-03):** One Clipboard execution on 0.3.82 using ODF-275's progress response (first contained in v0.3.74) where hosted proof was not the done floor. It is not ODF-275's qualifying hosted-proof event and is retained separately. Maintained guidance assessed at `325f9de8a1f635a44b0071cf0660a2593a21f6b9`.

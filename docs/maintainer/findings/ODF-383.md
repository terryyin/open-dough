## ODF-383 — A deletion-only amendment remaps the full source review

**Meaning:** A source change removing only a deferral triggers a full source-only review with different commitment IDs and a manual remap of existing observations.

**Follow-up:** Open, unqueued; not resolved.

**Identity / assessment (2026-11-01):** Distinct from ODF-326 identical-source reuse: the source did change. ODF-354’s amendment detection worked; the observed extra review/remap cost is a separate effect, not a failure to detect the amendment. Maintained guidance assessed at `d042a04e0fb53e3e3f66ddf6d9b34156e5785e2c`.

### Retained source evidence — open-dough / DD-375

**Source:** [open-dough / DearDough.md](https://github.com/terryyin/open-dough/blob/d042a04e0fb53e3e3f66ddf6d9b34156e5785e2c/DearDough.md).

**Source mapping:** open-dough / DD-375 → ODF-383.

When trunk amends the selected story during execution, the accept-proof rule
requires a fresh source-only review, replacing `source-review.md` and
re-allocating every id. An amendment that only deletes an exclusion sentence,
pointing at a sibling story that was dropped, changes no promise. The fresh
reviewer still numbers the commitments differently, so every row and every
earlier observation has to be remapped by hand.

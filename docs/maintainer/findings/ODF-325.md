## ODF-325 — Empty delegation while waiting

**Meaning:** A coordinator starts a no-op agent solely to stay active while real delegated work is pending, despite an existing waiting rule.

**Follow-up:** Open, unqueued; not resolved.

**Identity and limits:** New concrete issue at the supplied execution provenance. Related symptoms elsewhere do not establish a common cause. Existing guidance already forbids empty waiting calls; one observed violation warrants no wording response. Current maintained guidance assessed: `f274a3d0c729504bf8ce00614bf3cd236b7e088b` (source through 0.3.71); this is not substituted execution provenance.

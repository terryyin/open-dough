## ODF-343 — A mutating delivery is repeated to recover diagnostics

**Meaning:** A coordinator truncates a mutating delivery's diagnostics and repeats the command to learn the error, unintentionally crossing its commit boundary.

**Follow-up:** Open, unqueued; not resolved.

**Identity and limits:** New concrete issue at the supplied execution provenance. Related symptoms elsewhere do not establish a common cause. Existing Execute Plan guidance forbids mutating re-execution for diagnosis; preserve the unknown first failure cause. Current maintained guidance assessed: `f274a3d0c729504bf8ce00614bf3cd236b7e088b` (source through 0.3.71); this is not substituted execution provenance.

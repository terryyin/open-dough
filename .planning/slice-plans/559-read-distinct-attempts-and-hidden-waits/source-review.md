### Read distinct attempts, an adapter's selection, and waits a mean hides
Identity: SEED-284#read-distinct-attempts-and-hidden-waits
Goal. A developer whose project asks this skill to optimize tests gets a saving worth keeping that rests on distinct CI attempts, the test selection named even when the project reads CI through an adapter, and leads that a per-case mean does not hide. The correction is bounded to the retrospective findings for SEED-284#optimize-tests-from-ci-proof, which the Pygardon pilot exposed.
Scope. In src/skills/dough-test-optimization/references/evidence-and-leads.md: the variation behind the saving worth keeping comes from reader tables that name different attempts, reached through the revision before the previous table's attempt; the selection behind a CI adapter is traced from the adapter command the table's Source line names to the CI job and test command it reports; and a lead's mean per case is not taken as each case's cost before its cases' own waits or timings are read. The reader, the record formats and Intent stay unchanged.

Complete correction context (unsliced):
Three observed gaps: earlier requested revisions may read the same newest successful ancestor attempt, so comparing them can falsely show zero variation; adapter Selection remedy names CI configuration but no file, leaving the Source-line adapter command as the concrete route to the reported CI job/test selection; a 60.5 s file sum over two cases at mean 30.24 s hid one case's retry-sleep double's 60 s hang bound (the other case was 0.14 s).
Preserved constraints: reader attempt choice, table format, gaps and exit codes unchanged; guidance only. Discovery stays unadmitted and runs no fresh profiling run. Timing unmodified tests of a chosen lead stays permitted discovery. Saving worth keeping comes from developer target or evidence, without asking percentage, batch size or mode. One home per rule in evidence-and-leads.md; SKILL.md keeps linking it. Write for executing project, no Pygardon or Open Dough path in published guidance. Edit src/skills only, installed managed copies change only from released payload; no release in this correction.
Outside scope: automatic earlier-attempt selection in the reader; reader inferring adapter selection; unrelated pilot admission/Goal-label/quick-work/host-backgrounding/subagent-bridge/refactor-cost/Intent-Coverage improvements.

## ODF-378 — Trunk landing expectations block story-branch publication

**Meaning:** Implicit first-landing context resolution binds a trunk-targeted launch expectation to an intermediate story-branch publish and throws after committing.

**Follow-up:** Correction 0236e739 first released in v0.3.75; qualifying ordinary-use observation pending, not resolved. No implementation story is needed.

**Identity / assessment (2026-11-01):** Same concrete auto-resolution/target mismatch in all three projects. The affected 0.3.74 executions precede correction 0236e739; unknown execution releases remain unknown. Current source skips an implicit context whose remote/target differs; explicit contexts retain validation. The first containing tag is v0.3.75 (verified by numeric tag containment). Implementation is already delivered; a qualifying ordinary use with an open trunk expectation and successful intermediate publish remains unobserved. Maintained guidance assessed at `d042a04e0fb53e3e3f66ddf6d9b34156e5785e2c`.
